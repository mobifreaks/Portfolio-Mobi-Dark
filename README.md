# Portfolio Dark

Portfolio Dark: a dark portfolio template for phones, with a single-item view, contact page and typography reference.

**[Live demo](https://mobifreaks.github.io/Portfolio-Mobi-Dark/)** ·
[Download zip](https://github.com/mobifreaks/Portfolio-Mobi-Dark/archive/HEAD.zip) ·
[All 22 templates](https://munawarahmed.com/mobifreaks)

![Portfolio Dark on a phone](screenshot.webp)

## Use it

No build step. Download the zip, open `index.html`, and replace the placeholder text and images with your own.

## Tech

HTML and CSS. No JavaScript.
